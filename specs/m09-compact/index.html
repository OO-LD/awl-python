M9 awl.compact implementation plan¶

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

Goal: Encode an AstDoc into a compact form roughly a quarter its size and decode it back, so a visual editor can hold the workflow as its model.

Architecture: A pure encoder/decoder pair over plain dicts. Both ends speak AstDoc, so M5 and M9 compose. The encoder drops what is derivable; the decoder rebuilds every field the ast constructors require, from cls._fields.

Tech Stack: Python stdlib ast for _fields and reconstruction. No third-party dependency.

Contract¶
Consumes AstDoc (ast-doc.schema.json), as produced by ast2json or by M5
Produces CompactDoc (compact-doc.schema.json)
Depends on awl.contracts only. No sibling module.

The input type matters. An earlier draft operated on live ast.AST objects (isinstance(node, ast.Constant), node._fields) while its contract claimed AstDoc. M5 emits JSON, so the two could not compose and the pipeline never called M9 at all. The encoder now dispatches on _type keys.

Encoding rules:

_type            ->  _
Constant         ->  {"c": <value>}
Name             ->  {"$": <id>}
drop             ->  ctx, all position fields, None values, empty lists
carry through    ->  order, argumentIndex, argumentName  (M5's orderings)
optional         ->  "@": [lineno, col, end_lineno, end_col]   (spans, see below)

Size, measured¶

Form Bytes % of raw
ast2json raw 5425 100%
compact, from raw 1329 24%
compact, after M5 materializes the orderings 1477 27%
compact, with spans for the editor 2078 38%

The 24 to 27 point difference is order and argumentIndex. That is a real cost bought deliberately: it is what makes statement sequence queryable without RDF list traversal. State both numbers rather than quoting the flattering one.

Corrected after implementation. The span row previously read 1596 bytes / 29%, and the prose below said spans cost "about two percentage points". Measured against the implementation both are wrong: spans cost 13.8 points on this file and up to 16.4 on real/optimize_global.py. The earlier figure can only have come from spans on statements alone. Statement-only spans are cheaper and break what spans exist for, because M11 attributes trace events at expression level via co_positions() and M12 edits a literal by its own span. Measured range for the plain compact form across the whole corpus is 20.9% to 26.8%.

Spans are opt-in, and the editor needs them¶

The encoder drops position fields, which is most of the saving. But M12 addresses edits by span and M11 attributes trace events by span, so without spans there is no join key between the editor, the trace and the source. encode(doc, keep_spans=True) keeps a compact four-element "@" array, costing about fourteen percentage points, measured. The editor requests it; the RDF projection does not.

Non-goals¶

  • Not a projection. Elision by profile is M5.
  • Not a write-back path. Applying edits to source is M10.
  • Not schema-aware. A collapsed node encodes like any other typed node.

"""Compact AST codec: the editor model for AWL-LD workflows."""

from __future__ import annotations

import ast
from typing import Any

__all__ = ["encode", "decode"]

# Fields the ast constructors require as sequences. Anything absent from a
# compact document is rebuilt as an empty list, which is what lets the
# encoder drop them.
_LIST_FIELDS = frozenset({
    "args", "bases", "body", "comparators", "decorator_list", "defaults",
    "elts", "finalbody", "generators", "handlers", "items", "keywords",
    "kw_defaults", "kwonlyargs", "names", "ops", "orelse", "posonlyargs",
    "targets", "type_ignores", "type_params", "values",
})

# Derivable or positional; never carried.
_DROP = frozenset({
    "ctx", "col_offset", "end_col_offset", "end_lineno", "lineno",
    "type_comment", "kind", "n", "s",
})

# M5's orderings and the optional span ride alongside a shorthand node.
_CARRY = ("order", "argumentIndex", "argumentName")
_SHORTHAND_EXTRA = frozenset({"@", *_CARRY})


def encode(doc: Any, *, keep_spans: bool = False) -> Any:
    """Encode an AstDoc into the compact form.

    Parameters
    ----------
    doc : dict or list
        An ``AstDoc``, from ``ast2json`` or from M5.
    keep_spans : bool
        Keep a compact ``"@"`` span array. The editor and the trace overlay
        need it as a join key; the RDF projection does not. Costs about two
        percentage points of size.

    Returns
    -------
    dict or list
        A ``CompactDoc``.
    """
    if isinstance(doc, list):
        return [encode(item, keep_spans=keep_spans) for item in doc]
    if not isinstance(doc, dict):
        return doc

    node_type = doc.get("_type")
    plain = set(doc) - _DROP - {"_type", *_CARRY}

    if node_type == "Constant" and plain <= {"value"}:
        node: dict[str, Any] = {"c": doc.get("value")}
    elif node_type == "Name" and plain <= {"id"}:
        node = {"$": doc.get("id")}
    else:
        node = {"_": node_type} if node_type else {}
        for key, value in doc.items():
            if key in _DROP or key == "_type":
                continue
            encoded = encode(value, keep_spans=keep_spans)
            if encoded is None or (isinstance(encoded, list) and not encoded):
                continue
            node[key] = encoded
        if keep_spans and "lineno" in doc:
            node["@"] = _span(doc)
        return node

    if keep_spans and "lineno" in doc:
        node["@"] = _span(doc)
    for field in _CARRY:
        if field in doc:
            node[field] = doc[field]
    return node


def _span(doc: dict[str, Any]) -> list[Any]:
    return [
        doc.get("lineno"), doc.get("col_offset"),
        doc.get("end_lineno"), doc.get("end_col_offset"),
    ]


def decode(node: Any) -> Any:
    """Decode the compact form back into an AST node.

    Rebuilds every field of the target class, which is what makes the
    encoder's omissions safe. See task 2.
    """
    if isinstance(node, list):
        return [decode(item) for item in node]
    if not isinstance(node, dict):
        return node

    if "c" in node and set(node) <= {"c", *_SHORTHAND_EXTRA}:
        return ast.Constant(value=node["c"])
    if "$" in node and set(node) <= {"$", *_SHORTHAND_EXTRA}:
        return ast.Name(id=node["$"], ctx=ast.Load())

    cls = getattr(ast, node["_"])
    kwargs: dict[str, Any] = {}
    for field in cls._fields:
        if field in node:
            kwargs[field] = decode(node[field])
        elif field == "ctx":
            kwargs[field] = ast.Load()
        else:
            kwargs[field] = [] if field in _LIST_FIELDS else None
    return cls(**kwargs)

Task 2: Pin the reconstructing-decoder requirement¶

The reason is version portability, which is easy to get wrong.

Python ast.unparse on a Module with no type_ignores
3.11.6 AttributeError: 'Module' object has no attribute 'type_ignores'
3.13.1 Returns 'b = 1'

CPython became more tolerant between the two. The package supports 3.11 upward, so a decoder that only copies present keys passes on a new interpreter and breaks on an old one. Do not write the test as "a naive decoder raises": that assertion is itself version-dependent and fails on 3.13 for the opposite reason.

  • [ ] Step 1: Write the tests
def test_decoder_populates_every_field_of_the_node():
    """Asserting the fields are present is version-independent;
    asserting the failure mode is not.
    """
    node = decode(encode(ast2json(ast.parse("b = 1"))))
    missing = [f for f in type(node)._fields if not hasattr(node, f)]
    assert not missing, f"decoder left {missing} unreconstructed"


def test_encoder_drops_empty_required_lists():
    """Otherwise the test above passes vacuously."""
    assert "type_ignores" not in encode(ast2json(ast.parse("b = 1")))

import pytest

from awl import contracts
from awl.elide import elide


@pytest.mark.parametrize("path", contracts.corpus_files(), ids=lambda p: f"{p.parent.name}/{p.name}")
def test_round_trips_every_corpus_file(path):
    source = path.read_text(encoding="utf-8")
    tree = ast.parse(source)
    restored = decode(encode(ast2json(tree)))
    assert ast.unparse(ast.fix_missing_locations(restored)) == ast.unparse(tree)


def test_composes_with_the_elide_stage():
    """M5 emits AstDoc and M9 consumes AstDoc, so the pipeline can chain them.

    An earlier draft consumed live ast objects and silently could not.
    """
    source = (contracts.CORPUS_DIR / "tier2_dataclass" / "procedure.py").read_text(encoding="utf-8")
    tree = ast.parse(source)
    doc = elide(ast2json(tree), profile="ast")
    restored = decode(encode(doc))
    assert ast.unparse(ast.fix_missing_locations(restored)) == ast.unparse(tree)


def test_the_orderings_survive_encoding():
    """M5's order is the query surface; losing it here would empty F7."""
    source = (contracts.CORPUS_DIR / "tier2_dataclass" / "procedure.py").read_text(encoding="utf-8")
    doc = elide(ast2json(ast.parse(source)), profile="workflow")
    assert '"order"' in __import__("json").dumps(encode(doc))

Task 4: Size targets, and spans for the editor¶

import json


def test_compact_form_is_about_a_quarter_of_raw():
    """Measured 24% from raw, 27% after M5 materializes the orderings."""
    source = (contracts.CORPUS_DIR / "tier2_dataclass" / "procedure.py").read_text(encoding="utf-8")
    raw_doc = ast2json(ast.parse(source))
    raw = len(json.dumps(raw_doc))
    assert len(json.dumps(encode(raw_doc))) / raw < 0.27
    assert len(json.dumps(encode(elide(raw_doc, profile="ast")))) / raw < 0.30


def test_spans_are_available_when_requested():
    """Without these there is no join key between editor, trace and source."""
    source = "charge(ChargeParam(target_voltage=4.2))\n"
    doc = encode(ast2json(ast.parse(source)), keep_spans=True)
    found = json.dumps(doc)
    assert '"@"' in found, "spans present"
    assert '"c": 4.2' in found


def test_spans_are_absent_by_default():
    doc = encode(ast2json(ast.parse("x = 1\n")))
    assert '"@"' not in json.dumps(doc)

Acceptance¶

  • [ ] decode(encode(doc)) unparses identically for every corpus file.
  • [ ] The encoder consumes an AstDoc, so M5 and M9 compose.
  • [ ] order, argumentIndex and argumentName survive encoding.
  • [ ] Compact output is under 27% of raw, and under 30% after M5's orderings.
  • [ ] keep_spans=True emits "@"; the default does not.
  • [ ] Every encoded node validates against compact-doc.schema.json.
  • [ ] tests/test_compact.py imports only awl.compact, awl.elide, awl.contracts and ast2json.

Known limits¶

  • Comments and formatting are absent, because ast.parse discards them. Source fidelity belongs to M10, by patching spans rather than regenerating.
  • A new AST node with a required list field must be added to _LIST_FIELDS. Task 2 catches that only if CI keeps running the oldest supported interpreter; on 3.13 the same defect is silent.
  • contracts.validate must accept the carried order, argumentIndex, argumentName and "@" keys. If compact-doc.schema.json forbids them on the shorthand forms, that is a contract change and M0 must be updated first.
