M5 awl.elide implementation plan¶

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

Goal: Apply a cutoff profile to an AstDoc: materialize the two orderings, fold keyword arguments into their call, drop plumbing, and keep the ast profile round-trippable.

Architecture: A pure AstDoc -> AstDoc transform driven by M1's declared sets. Three behaviours, not one: order, fold, elide.

Tech Stack: Python stdlib.

Contract¶
Consumes AstDoc plus a profile name, optionally the original source
Produces AstDoc
Depends on awl.contracts, awl.vocab

Three mechanisms¶

Order. Every element of an ordered statement list gets order, its sibling slot. Every positional call argument gets argumentIndex (1..N). This is the materialized integer index that makes statement sequence queryable without rdf:rest*/rdf:first traversal, so M5 is where F7's ordering query gets its data.

Fold. A keyword node merges into its parent Call as keywordArguments: {name: value}, and the value carries argumentName plus argumentIndex: -1.

Elide. A transparent type is unwrapped into its parent. An opaque type emits one node keeping its source text.

The regression this design exists to prevent¶

An earlier draft treated keyword as transparent and spliced out.get("value", out.get("arg", ...)), which returns the value and discards the name. Measured:

original : charge(ChargeParam(target_voltage=4.2, c_rate=0.23))
restored : while i < cycles:charge(ChargeParam(4.2, 0.23))rest(600)

Named arguments became positional (a semantic change, not a formatting one), Expr transparency flattened statements onto one line, and M6 could then never collapse because keyword.arg was None. One line of splice logic broke F4, F3 and F7 together. Task 1 pins it.

Preserve the frontend label¶

Following CPG's PARSER_TYPE_NAME, the Python-specific label rides as a property, not as the node type:

{"_type": "Call", "parserTypeName": "BinOp", "sourceText": "i < cycles"}

Non-goals¶

  • Not the collapse. Type-driven rewriting is M6.
  • Not compaction. Re-encoding is M9.

"""Profile-driven cutoff: order, fold, elide."""

from __future__ import annotations

from typing import Any

from awl.vocab import FOLDS_KEYWORDS, OPAQUE, ORDERED_FIELDS, TRANSPARENT

__all__ = ["elide"]


def elide(doc: Any, *, profile: str = "ast", source: str = "") -> Any:
    """Apply a cutoff profile to an AST document.

    Parameters
    ----------
    doc : dict or list
        An ``AstDoc``.
    profile : str
        One of ``awl.vocab.PROFILES``.
    source : str, optional
        Original text, used to populate ``sourceText`` on opaque nodes. Without
        it an opaque node keeps its type but loses its expression.

    Returns
    -------
    dict or list
        A new document; the input is not mutated.

    Raises
    ------
    KeyError
        If the profile is unknown, rather than silently doing nothing.
    """
    return _walk(doc, TRANSPARENT[profile], OPAQUE[profile], FOLDS_KEYWORDS[profile], source)


def _walk(node, transparent, opaque, folds_keywords, source):
    if isinstance(node, list):
        return [_walk(i, transparent, opaque, folds_keywords, source) for i in node]
    if not isinstance(node, dict):
        return node

    node_type = node.get("_type")

    if node_type in opaque:
        return {
            "_type": "Call",
            "parserTypeName": node_type,
            "sourceText": _source_text(node, source),
        }

    out = {}
    for key, value in node.items():
        walked = _walk(value, transparent, opaque, folds_keywords, source)
        if isinstance(walked, list) and not walked:
            continue
        out[key] = walked

    _materialize_order(out)
    if node_type == "Call":
        _index_arguments(out, folds_keywords)

    if node_type in transparent:
        payload = out.get("value")
        if payload is not None:
            if isinstance(payload, dict) and "order" in out:
                payload["order"] = out["order"]
            return payload
    return out


def _materialize_order(out):
    """Give every statement its sibling slot: the query surface for order."""
    for field in ORDERED_FIELDS:
        sequence = out.get(field)
        if isinstance(sequence, list):
            for position, child in enumerate(sequence):
                if isinstance(child, dict):
                    child["order"] = position


def _index_arguments(out, folds_keywords):
    """Bind arguments to parameters, and fold keywords preserving their names."""
    for position, argument in enumerate(out.get("args", []) or []):
        if isinstance(argument, dict):
            argument["argumentIndex"] = position + 1

    if not folds_keywords:
        return

    folded = {}
    for keyword in out.get("keywords", []) or []:
        if isinstance(keyword, dict) and keyword.get("arg"):
            value = keyword.get("value")
            if isinstance(value, dict):
                value["argumentName"] = keyword["arg"]
                value["argumentIndex"] = -1
            folded[keyword["arg"]] = value
    if folded:
        out["keywordArguments"] = folded
        out.pop("keywords", None)


def _source_text(node, source):
    """Return the original text of an opaque node, or "" when unavailable."""
    if not source or "lineno" not in node:
        return ""
    lines = source.splitlines()
    start, end = node.get("lineno"), node.get("end_lineno", node.get("lineno"))
    if not start or start > len(lines):
        return ""
    if start == end:
        return lines[start - 1][node.get("col_offset", 0) : node.get("end_col_offset")]
    return "\n".join(lines[start - 1 : end])

def _find(doc, predicate):
    if isinstance(doc, dict):
        if predicate(doc):
            return doc
        for value in doc.values():
            found = _find(value, predicate)
            if found:
                return found
    elif isinstance(doc, list):
        for item in doc:
            found = _find(item, predicate)
            if found:
                return found
    return None


def test_statements_carry_a_contiguous_order():
    """The materialized index. Verified: [0, 1] for the tier 2 procedure."""
    source = (contracts.CORPUS_DIR / "tier2_dataclass" / "procedure.py").read_text(encoding="utf-8")
    doc = elide(ast2json(ast.parse(source)), profile="workflow")
    procedure = _find(doc, lambda d: d.get("_type") == "FunctionDef")
    orders = [statement.get("order") for statement in procedure["body"]]
    assert orders == list(range(len(orders))), orders


def test_a_folded_keyword_keeps_its_name_and_is_marked_named():
    source = (contracts.CORPUS_DIR / "tier2_dataclass" / "procedure.py").read_text(encoding="utf-8")
    doc = elide(ast2json(ast.parse(source)), profile="workflow")
    call = _find(doc, lambda d: d.get("func", {}).get("id") == "ChargeParam")
    assert set(call["keywordArguments"]) == {"target_voltage", "c_rate"}
    assert call["keywordArguments"]["target_voltage"]["argumentName"] == "target_voltage"
    assert call["keywordArguments"]["target_voltage"]["argumentIndex"] == -1, "-1 means named"


def test_positional_arguments_are_numbered_from_one():
    """0 is reserved for an implicit receiver, per the CPG convention."""
    doc = elide(ast2json(ast.parse("f(a, b)\n")), profile="workflow")
    call = _find(doc, lambda d: d.get("_type") == "Call")
    assert [a["argumentIndex"] for a in call["args"]] == [1, 2]

import json


def test_the_workflow_profile_is_smaller_than_ast():
    source = (contracts.CORPUS_DIR / "tier2_dataclass" / "procedure.py").read_text(encoding="utf-8")
    raw = ast2json(ast.parse(source))
    sizes = {p: len(json.dumps(elide(raw, profile=p))) for p in ("ast", "workflow", "signature")}
    assert sizes["workflow"] < sizes["ast"], sizes
    assert sizes["signature"] <= sizes["workflow"], sizes


def test_an_unknown_profile_raises():
    with pytest.raises(KeyError):
        elide({"_type": "Module"}, profile="invented")


def test_the_frontend_label_survives_elision():
    doc = elide(ast2json(ast.parse("x = a < b\n")), profile="workflow", source="x = a < b\n")
    opaque = _find(doc, lambda d: d.get("parserTypeName") == "Compare")
    assert opaque is not None
    assert opaque["sourceText"] == "a < b", "the expression is kept as text, not lost"

Acceptance¶

  • [ ] The ast profile round-trips for every corpus file, including the vendored scipy file.
  • [ ] A named argument never becomes positional at any profile.
  • [ ] Statements carry a contiguous order; positional arguments carry argumentIndex from 1; named ones carry -1 plus argumentName.
  • [ ] An opaque node keeps its expression as sourceText when source is supplied.
  • [ ] An unknown profile raises.
  • [ ] tests/test_elide.py imports only awl.elide, awl.vocab, awl.contracts, and ast2json/json2ast.

Known limits¶

  • The transparent-splice rule reads value, which is Python-specific. The sets live in M1 and are what a second frontend replaces, but the splice key will need declaring too. Noting rather than generalising speculatively.
  • provenance and signature share workflow's sets, so all three currently produce the same document. Their distinguishing behaviour needs a predicate this module does not yet take. The size test asserts signature <= workflow, which passes on equality, and that is honest rather than aspirational.
  • sourceText requires the caller to pass source. When it is omitted an opaque node keeps its type and loses its expression, which is a real loss at the workflow profile. M14 must thread the source through.
