M3 awl.facts implementation plan¶

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

Goal: Read out of source, without inference and without importing it, everything a later pass needs: what is declared, what is imported, and what each annotated type means.

Architecture: A single AST walk producing two documents. SymbolFacts records what was literally seen. TypeInfo records the shape of each LinkedBaseModel subclass. Nothing here decides what a name refers to; that is M4.

Tech Stack: Python stdlib ast. No imports of user code, ever.

Contract¶
Consumes source text plus its module path
Produces SymbolFacts and TypeInfo
Depends on awl.contracts, awl.ids

Observation, never inference¶

Graphify's separation, and the reason it matters: extraction that guesses cannot be audited, and a wrong guess is indistinguishable from an observation once it is in the graph. So this module records from battery.params import ChargeParam as an import fact with an alias hop and stops. Whether ChargeParam at a given call site is that class is M4's judgement, and it carries a confidence tier.

Emit both the alias hop and the resolved-to-root target, following Kythe's aliases and aliases/root pair, so a query chooses its own indirection level. Re-exports are the likeliest source of duplicate nodes in Python.

All five SymbolFacts members, not just imports¶

declarations, imports, aliases, exports, uses. uses is what M4 iterates, exports is what its re-export resolution reads, and declarations carries tier 2. A draft of this spec populated only imports and left the rest as empty lists, which left M4 with nothing to bind.

declarations is the tier 2 rung, and it is not optional¶

F2's acceptance is "field names, annotations and ranges extracted; classes identified by import path", and that applies to any class, including a plain @dataclass , not only to LinkedBaseModel subclasses.

A draft of this spec extracted nothing for tier 2 and asserted only types == []. That put tier 1 and tier 2 on the same rung and turned the progressive-enhancement gradient into a cliff, which is the one claim the corpus was purpose-built to measure.

The split, which is the gradient expressed as two outputs:

Tier declarations TypeInfo
1, plain the function, its parameters none
2, dataclass the class, its fields, their annotations, its import-path identity none
3, OO-LD as tier 2 declared IRIs, link forms, union arms

The notation, and both of its forms¶

Target is the OO-LD notation, being renamed to LinkedBaseModel and LinkedField:

class ChargeParam(LinkedBaseModel):
    id: str | None = None
    type: str | None = "ex:ChargeParam"

    target_voltage: float
    device: Link[Device] | None = None                  # form A
    calibrated_against: Device | None = LinkedField(link=True)   # form B
    operator: str | Device | None = LinkedField(link=True)       # union arms

Both link forms are first class. Neither is a migration stage, so neither may be treated as canonical. Link[T] is Annotated[T, LinkMarker()], which is statically visible, so this is achievable without importing anything.

Per field, record: name, isLink, isMany, target, declarationForm, and the union arms drawn from the OO-LD spec's three value forms:

Arm Instance shape Projects to
literal a bare scalar an RDF literal
reference an object with @id or id an IRI
embedded a nested object with no id a blank node

Where the instance type comes from¶

Verified against spec/sections/07-schema-instances.md:

  1. x-oold-instance-rdf-type on the schema, a list, because it co-types. Under allOf the nearest declaration replaces rather than appends (rule OOLD-INS-559f).
  2. The inline type field default. If both exist the inline value must be consistent (rule OOLD-INS-4b5c).
  3. The import path.

Minting is M2's job; this module supplies the inputs.

The cross-repository hazard¶

oold/experimental/notation.py:_unwrap() already resolves an annotation into (target, is_link, is_many, arms) at runtime. This module needs the same judgement statically. Do not restate the semantics: two producers of one judgement that disagree is the graphify/ids.py failure a level up. Build the reader so it works for both repositories, then open an issue on oold-python proposing it move there. Until it does, AWL owns it behind the M0 adapter.

Non-goals¶

  • Not resolution, confidence, or identity minting.
  • Not runtime introspection. Static analysis only, because tier 3 of the corpus references an oold branch that need not be installed.

"""Observation: what the source says, with nothing inferred."""

from __future__ import annotations

import ast
from typing import Any

__all__ = ["extract"]


def extract(source: str, *, module: str, file: str = "<source>") -> dict[str, Any]:
    """Read symbol facts and type info out of one module.

    Never imports the module. Never decides what a name refers to.

    Returns
    -------
    dict
        Conforms to ``symbol-facts.schema.json``.
    """
    tree = ast.parse(source)
    facts: dict[str, Any] = {
        "file": file,
        "declarations": [],
        "imports": [],
        "aliases": [],
        "exports": [],
        "uses": [],
        "types": [],
    }
    for node in ast.walk(tree):
        if isinstance(node, ast.ImportFrom):
            prefix = "." * (node.level or 0)
            for alias in node.names:
                facts["imports"].append(
                    {
                        "localName": alias.asname or alias.name,
                        "importedName": alias.name,
                        "fromModule": prefix + (node.module or ""),
                        "isAlias": alias.asname is not None,
                    }
                )
        elif isinstance(node, ast.Import):
            for alias in node.names:
                facts["imports"].append(
                    {
                        "localName": alias.asname or alias.name.split(".")[0],
                        "importedName": alias.name,
                        "fromModule": "",
                        "isAlias": alias.asname is not None,
                    }
                )
    return facts

Task 1b: Populate uses, exports and declarations¶

M4 iterates uses and reads exports; without them it has nothing to bind and every downstream test passes vacuously. An earlier draft left all three as empty lists.

def test_every_call_site_becomes_a_use():
    """M4 binds uses, so an unpopulated list silently disables resolution."""
    facts = extract(TIER2.read_text(encoding="utf-8"), module="tier2_dataclass.procedure")
    used = {u["localName"] for u in facts["uses"]}
    assert {"charge", "rest", "ChargeParam"} <= used
    for use in facts["uses"]:
        assert use["span"]["startLine"] >= 1, "a use without a span cannot be attributed"


def test_a_function_becomes_a_declaration():
    facts = extract(TIER2.read_text(encoding="utf-8"), module="tier2_dataclass.procedure")
    procedure = next(d for d in facts["declarations"] if d["name"] == "procedure")
    assert procedure["kind"] == "function"
    assert [p["name"] for p in procedure["parameters"]] == ["cycles"]
    assert procedure["parameters"][0]["annotation"] == "int"


def test_module_level_names_become_exports():
    """What another module could import from here; M4's re-export input."""
    facts = extract(TIER2.read_text(encoding="utf-8"), module="tier2_dataclass.procedure")
    assert "procedure" in {e["exportedName"] for e in facts["exports"]}

def test_reads_both_link_declaration_forms():

    facts = extract(TIER3.read_text(encoding="utf-8"), module="tier3_oold.params")

    assert fields["device"]["isLink"] is True
    assert fields["device"]["target"] == "Device"

    assert fields["calibrated_against"]["declarationForm"] == "LinkedField(link=True)"
    assert fields["calibrated_against"]["isLink"] is True
    assert fields["calibrated_against"]["target"] == "Device"


def test_a_plain_field_is_not_a_link():

def test_the_type_field_default_is_recorded():
    facts = extract(TIER3.read_text(encoding="utf-8"), module="tier3_oold.params")
    charge = next(t for t in facts["types"] if t["identity"]["symbol"] == "ChargeParam")
    assert charge["declaredTypes"] == ["ex:ChargeParam"]


def test_a_dataclass_yields_fields_but_no_type_info():
    """Tier 2 is a rung, not a gap. F2's acceptance criterion.

    A plain dataclass has no IRIs, so no TypeInfo. It does have fields,
    annotations and an import-path identity, so it must still produce a
    declaration. Without this, tier 1 and tier 2 are indistinguishable and
    the gradient has a cliff exactly where the corpus measures it.
    """
    tier2_params = (contracts.CORPUS_DIR / "tier2_dataclass" / "params.py").read_text(encoding="utf-8")
    facts = extract(tier2_params, module="tier2_dataclass.params")

    assert facts["types"] == [], "no IRIs, so no TypeInfo"

    charge = next(d for d in facts["declarations"] if d["name"] == "ChargeParam")
    assert charge["kind"] == "class"
    assert charge["identity"]["iri"].endswith("tier2_dataclass.params/ChargeParam")
    fields = {f["name"]: f for f in charge["fields"]}
    assert set(fields) == {"target_voltage", "c_rate"}
    assert fields["target_voltage"]["annotation"] == "float"


def test_the_gradient_is_measurable_across_the_tiers():
    """Each tier must yield strictly more than the one below it."""
    def counts(tier, name):
        source = (contracts.CORPUS_DIR / tier / name).read_text(encoding="utf-8")
        facts = extract(source, module=f"{tier}.{name[:-3]}")
        return len(facts["declarations"]), len(facts["types"])

    plain = counts("tier1_plain", "procedure.py")
    typed = counts("tier2_dataclass", "params.py")
    oold = counts("tier3_oold", "params.py")

    assert typed[0] > 0, "tier 2 declares fields"
    assert typed[1] == 0 and oold[1] > 0, "only tier 3 has declared IRIs"
    assert plain[1] == 0


def test_output_matches_the_contract():
    facts = extract(TIER3.read_text(encoding="utf-8"), module="tier3_oold.params")
    contracts.validate(facts, "symbol-facts")

Acceptance¶

  • [ ] Import facts carry the alias hop and the imported name separately.
  • [ ] Both link declaration forms produce identical TypeInfo shapes.
  • [ ] Union arms are recorded as literal, reference, embedded.
  • [ ] The tier 3 corpus file is read without being imported.
  • [ ] A plain dataclass produces no TypeInfo.
  • [ ] Output validates against symbol-facts.schema.json.
  • [ ] tests/test_facts.py imports only awl.facts, awl.ids and awl.contracts.

Known limits¶

  • Star imports are recorded as a fact and never resolved. The sound answer is to make import * illegal in the workflow domain's JSON Schema, which is what the restriction objective is for.
  • Dynamically constructed classes are invisible to static analysis, by design.
  • x-oold-instance-rdf-type lives in a schema file, not in the Python source. Reading it needs the schema, so until M7 resolves schemas this module can only see the inline type default. State that rather than pretending otherwise.
