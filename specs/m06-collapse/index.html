M6 awl.collapse implementation plan¶

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

Goal: Rewrite a call whose callee resolves to an annotated type into a single typed node, interpreted by that type's own context, so the call site carries meaning without the author writing any linked data.

Architecture: AstDoc in, AstDoc out, guided by ResolvedNames and TypeInfo. The rewritten node carries an embedded @context setting @vocab to the resolved namespace, so its keyword arguments become properties of the type rather than of AWL.

Tech Stack: Python stdlib.

Contract¶
Consumes AstDoc, ResolvedNames, TypeInfo
Produces AstDoc with collapsed nodes
Depends on awl.contracts, awl.ids

This is the contribution¶

The survey found no precedent for the mechanism. FnO reaches the same semantic target from a different direction, and semantikon is a live implementation of types-carrying-semantics, but both attach semantics to a declared signature. This attaches them by rewriting a call site's AST subtree using the resolved callee's context. No code-indexing system does that: they all keep the call as a call and merely point at the callee.

Claim the mechanism, not the goal.

What the notation gives for free¶

Cheaper than the analysis originally assumed, because the notation declares what the collapse would otherwise infer:

Needed Source
Property range Link[T] supplies it statically. No schema resolution, no relative @context refs
Literal vs reference vs embedded The declared union arms
Blank node An embedded arm with no id
Property namespace The resolved type identity

Defined over parameter names, not keyword syntax¶

The collapse must key on the resolved callee's field names, never on Python's keyword-argument syntax. Python keyword arguments have no TypeScript equivalent, so a syntax-keyed collapse would not survive a second frontend even though its output would be identical. This is why M1 separates the syntactic sibling order from the argument binding order.

Acceptance case¶

The .pint.magnitude case from tensile_test.py:

slope, *_ = linregress(
    linear["strain"].pint.to_base_units().pint.magnitude,
    linear["stress"].pint.to_base_units().pint.magnitude,
)
dataset.specimen.e_mod = ModulusOfElasticity.from_pint(slope.to("Pa"))

Units are stripped before the call, so what crosses the boundary is dimensionless float arrays. (LinearStrain, Stress) describes values three attribute accesses upstream. Recovering that requires tracing back through a third-party wrapper chain, and it is the hardest concrete case in the corpus. Treat it as the acceptance test, not as a first task.

Non-goals¶

  • Not resolution. Which type a name refers to is M4.
  • Not context authoring. Emitting the document-level context is M7; this emits only the per-node embedded context.

"""Type-driven collapse of call subtrees into typed nodes."""

from __future__ import annotations

from typing import Any

__all__ = ["collapse"]


def collapse(doc: Any, *, types: dict[str, Any], resolved: dict[str, str]) -> Any:
    """Rewrite resolved constructor calls into typed nodes.

    Parameters
    ----------
    doc : dict or list
        An ``AstDoc``.
    types : dict
        ``TypeInfo`` keyed by symbol name.
    resolved : dict
        Local name to symbol name, from M4. A name absent here is not
        collapsed, which is how AMBIGUOUS bindings stay uncollapsed.

    Returns
    -------
    dict or list
        A new document.
    """
    if isinstance(doc, list):
        return [collapse(item, types=types, resolved=resolved) for item in doc]
    if not isinstance(doc, dict):
        return doc

    if doc.get("_type") == "Call":
        callee = doc.get("func", {}).get("id")
        symbol = resolved.get(callee)
        info = types.get(symbol) if symbol else None
        if info is not None:
            return _typed_node(doc, info, types=types, resolved=resolved)

    return {k: collapse(v, types=types, resolved=resolved) for k, v in doc.items()}


def _typed_node(call: dict[str, Any], info: dict[str, Any], **kw: Any) -> dict[str, Any]:
    """Build the typed node, keyed on the callee's declared field names.

    Two things that were wrong in an earlier draft:

    - The namespace comes from the **minted** IRI, which is resolvable, never
      from a declared CURIE. `ex:ChargeParam#target_voltage` validates and
      joins with nothing.
    - Arguments are read from `keywordArguments`, which M5 folds while
      preserving the name. Reading `keywords[].arg` returned None once M5
      ran, so the collapse silently never fired.
    """
    namespace = info["identity"]["iri"] + "#"
    fields = {f["name"] for f in info["fields"]}

    node: dict[str, Any] = {
        "@context": {"@vocab": namespace},
        "@type": info["declaredTypes"][0] if info["declaredTypes"] else info["identity"]["iri"],
        # Reversibility. `@type` is an IRI, not the Python name written in the
        # source, so without `_callee` the node cannot be unparsed back.
        "_callee": call.get("func", {}).get("id"),
        "@": [
            call.get("lineno"), call.get("col_offset"),
            call.get("end_lineno"), call.get("end_col_offset"),
        ],
    }
    if "order" in call:
        node["order"] = call["order"]

    arguments = call.get("keywordArguments")
    if arguments is None:
        # M5 has not folded (the `ast` profile), so nothing to collapse.
        return {k: collapse(v, **kw) for k, v in call.items()}

    for name, value in arguments.items():
        if name not in fields:
            # Not a declared field: leave the call uncollapsed rather than
            # inventing a property. Silent invention is the failure mode here.
            return {k: collapse(v, **kw) for k, v in call.items()}
        node[name] = (
            value.get("value") if isinstance(value, dict) and value.get("_type") == "Constant"
            else collapse(value, **kw)
        )
    return node

Task 1b: The collapse must be reversible¶

The collapse is not a projection, it is a representation change, so it needs an inverse. The whole point of the editor is: collapsed dict, edited as a form, expanded back, unparsed to source. Without expand() the editor can display a workflow and never write one.

The collapsed node is a flat editable dict, which is exactly what a schema-driven form consumes:

{
  "@context": {"@vocab": "https://w3id.org/awl/py/battery.params/ChargeParam#"},
  "@type": "ex:ChargeParam",
  "_callee": "ChargeParam",
  "@": [1, 7, 1, 51],
  "target_voltage": 4.2,
  "c_rate": 0.23
}

Two of those keys exist solely for the inverse. _callee is the local name as written; @type is an IRI and cannot supply it. @ is the span, so M10 can patch in place rather than regenerate.

def test_collapse_is_reversible():
    """Verified round trip: collapse, expand, unparse, byte-identical."""
    import ast

    from ast2json import ast2json
    from json2ast import json2ast

    from awl.collapse import collapse, expand
    from awl.elide import elide

    source = "charge(ChargeParam(target_voltage=4.2, c_rate=0.23))\n"
    doc = elide(ast2json(ast.parse(source)), profile="workflow")
    collapsed = collapse(doc, types=TYPES, resolved={"ChargeParam": "ChargeParam"})
    restored = ast.unparse(ast.fix_missing_locations(json2ast(expand(collapsed))))
    assert restored.strip() == source.strip()


def test_an_edit_made_in_the_form_survives_expansion():
    """The editor flow end to end: dict, edit, expand, unparse."""
    import ast
    import json

    from ast2json import ast2json
    from json2ast import json2ast

    from awl.collapse import collapse, expand
    from awl.elide import elide

    source = "charge(ChargeParam(target_voltage=4.2, c_rate=0.23))\n"
    doc = elide(ast2json(ast.parse(source)), profile="workflow")
    collapsed = collapse(doc, types=TYPES, resolved={"ChargeParam": "ChargeParam"})

    edited = json.loads(json.dumps(collapsed))          # as a form would return it
    _set(edited, "target_voltage", 4.1)

    out = ast.unparse(ast.fix_missing_locations(json2ast(expand(edited))))
    assert "target_voltage=4.1" in out
    assert "c_rate=0.23" in out, "the untouched field is unharmed"

_RESERVED = frozenset({"@context", "@type", "@", "_callee", "order"})


def expand(node: Any) -> Any:
    """Inverse of :func:`collapse`: a typed node back to a Call AstDoc.

    Field insertion order is the keyword order, which JSON and Python dicts
    both preserve, so the restored call reads as it was written.

    Raises
    ------
    ValueError
        If a typed node carries no ``_callee``. Emitting a call with a
        guessed name would be worse than refusing.
    """
    if isinstance(node, list):
        return [expand(item) for item in node]
    if not isinstance(node, dict):
        return node
    if "@type" in node and "_callee" not in node:
        raise ValueError("typed node has no _callee, so it cannot be expanded")
    if "_callee" not in node:
        return {key: expand(value) for key, value in node.items()}

    span = node.get("@") or [1, 0, 1, 0]
    position = {
        "lineno": span[0], "col_offset": span[1],
        "end_lineno": span[2], "end_col_offset": span[3],
    }
    keywords = []
    for name, value in node.items():
        if name in _RESERVED:
            continue
        inner = (
            expand(value) if isinstance(value, dict)
            else {"_type": "Constant", "value": value, **position}
        )
        keywords.append({"_type": "keyword", "arg": name, "value": inner, **position})

    return {
        "_type": "Call",
        "func": {"_type": "Name", "id": node["_callee"], "ctx": {"_type": "Load"}, **position},
        "args": [],
        "keywords": keywords,
        **position,
    }

Task 3: The collapse is lossless in RDF¶

The point of the embedded context. Without it the keyword names are unmapped terms and JSON-LD drops them, which is the defect measured in the current implementation.

import json


def test_the_collapsed_node_survives_the_rdf_projection():
    """Verified mechanism: an embedded @context sets @vocab to the type's
    namespace, so target_voltage becomes a property rather than vanishing.
    """
    from rdflib import Graph

    node = collapse(CALL, types=TYPES, resolved={"ChargeParam": "ChargeParam"})
    graph = Graph()
    graph.parse(data=json.dumps(node), format="json-ld")
    predicates = {str(p) for _, p, _ in graph}
    assert any(p.endswith("target_voltage") for p in predicates), predicates

Acceptance¶

  • [ ] A resolved constructor becomes one typed node with an embedded context.
  • [ ] An unresolved callee is left as a Call.
  • [ ] An undeclared keyword prevents collapse rather than inventing a property.
  • [ ] The collapsed node round-trips into RDF with its properties intact.
  • [ ] tests/test_collapse.py imports only awl.collapse, awl.ids and awl.contracts.

Known limits¶

  • Positional arguments are not collapsed. Mapping them needs the callee's parameter order, which TypeInfo records but which is not exercised by the corpus. Add it when a fixture needs it.
  • The .pint.magnitude chain may prove unfollowable statically. That is an acceptable outcome, provided it is documented and the call stays uncollapsed rather than being guessed.
