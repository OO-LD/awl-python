M1 awl.vocab implementation plan¶

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

Goal: A language-neutral node vocabulary, the two orderings, the per-profile elision sets and the ambient-noise lists, as pure data, so the cutoff is a declaration rather than logic buried in a walker.

Architecture: Constants only, no behaviour. Modelled on Joern's Code Property Graph. Python-specific labels survive as a parserTypeName property rather than as node types.

Tech Stack: Python stdlib ast for the mapping keys. No dependency.

Contract¶
Consumes nothing
Produces constants read by M5, M6, M7
Depends on awl.contracts only, and only for the profile names

Why not one RDF class per ast node type¶

Joern has no ASSIGNMENT node: x = y + 1 is a CALL named <operator>.assignment. CodeQL uses one exprs table keyed (parent, idx). CodeOntology minted a class per construct and was last pushed 2018-06-27. Beyond the maintenance evidence, a class-per-node vocabulary versions AWL-LD against the CPython grammar forever. Measured on 3.11.6: 27 statement types, 32 expression types, 13 binary operators, 10 comparison operators. The exact counts move between releases, which is the point.

The vocabulary¶

Twelve node types. Nothing below is Python-specific.

Type Covers
Method FunctionDef, AsyncFunctionDef, Lambda. Procedures, functions and methods are one type
Block Module, and any statement-list body
Call Call, and every operator
ControlStructure If, While, For, AsyncFor, With, AsyncWith, Try, TryStar, Match, Break, Continue. Discriminated by a controlStructureType property, not by one class per construct
Identifier Name
Literal Constant, JoinedStr, FormattedValue
Local a name bound in a method body
Return Return, Yield, YieldFrom, Await
TypeDecl ClassDef
Type an annotation position
Member AnnAssign at class scope
Unknown anything unmapped, carrying parserTypeName

Operators become calls with a reserved name:

Python Call name
Assign, AnnAssign <operator>.assignment
AugAssign <operator>.assignmentPlus and siblings
BinOp <operator>.addition, .subtraction, ...
Compare <operator>.lessThan, .equals, ...
Attribute <operator>.fieldAccess
Subscript <operator>.indexAccess

The two orderings¶

Verified against the CPG specification, and not optional: conflating them breaks the collapse boundary, which is where a call's keywords become a type's named properties.

Property Meaning
order Syntactic sibling slot within an ordered statement list. Leftmost is 0
argumentIndex Binds a call-site argument to a callee parameter. Positional args are 1..N; -1 means the argument is named, and argumentName carries the name

order is also the materialized integer index that makes statement sequence queryable without rdf:rest*/rdf:first traversal. M5 emits both.

Profiles¶

Three declared behaviours per profile, not two.

Profile Transparent (unwrapped) Folds keywords Opaque (one node, source text)
ast nothing no nothing
workflow Expr, arguments, alias yes BinOp, BoolOp, UnaryOp, Compare
provenance Expr, arguments, alias yes as workflow, plus non-boundary calls
signature Expr, arguments, alias yes as workflow, plus all bodies

ast elides nothing structural. An earlier draft made Expr and keyword transparent at every profile. Measured consequence: charge(ChargeParam(target_voltage=4.2, c_rate=0.23)) restored as ChargeParam(4.2, 0.23) and the loop body flattened to one line. Named arguments silently became positional, which is a semantic change, and the collapse could then never fire because keyword.arg was gone. ast now drops only positions and empty lists, both of which the decoder reconstructs, so it round-trips.

keyword is never transparent, it folds. Folding merges it into the parent Call as keywordArguments: {name: value}, preserving the name and setting argumentIndex: -1 plus argumentName. This is the analysis's "collapsing keyword into a dict on the Call", which preserves rather than discards.

A third condition is content-dependent and lives in M6: a call collapses if and only if its callee resolves to an annotated type.

Ambient vocabulary¶

Owned here, as data. The principle transfers from Graphify; the contents invert, because Graphify's lists encode what a repository is about and these must encode what a workflow is about. Graphify lists dataclass as noise; here an annotated base class is signal.

Start deliberately small and grow from evidence on the real corpus file, which is roughly half matplotlib. Over-filtering strips meaningful calls; under-filtering fills the graph with plotting.

Non-goals¶

  • Not a walker. Applying these sets is M5.

import ast

from awl.vocab import NODE_TYPES, node_type_for


def test_every_ast_node_type_maps_to_the_vocabulary():
    """No node may be silently unmapped. Unknown is a legitimate answer."""
    unmapped = [
        name
        for name in dir(ast)
        if isinstance(getattr(ast, name), type)
        and issubclass(getattr(ast, name), ast.AST)
        and node_type_for(name) not in NODE_TYPES
    ]
    assert not unmapped, f"unmapped: {unmapped}"

    A new Python version adding a node type must surface as Unknown here, and

    assert node_type_for("SomeFuturePython315Node") == "Unknown"

"""Language-neutral node vocabulary, orderings, profiles and noise lists.

Pure data. Modelled on Joern's Code Property Graph so a second language
frontend does not require a second vocabulary.
"""

from __future__ import annotations

from types import MappingProxyType

__all__ = [
    "NODE_TYPES", "PROFILES", "TRANSPARENT", "OPAQUE", "FOLDS_KEYWORDS",
    "ORDERED_FIELDS", "AMBIENT_CALLEES", "AMBIENT_ANNOTATIONS",
    "node_type_for", "operator_name_for",
]

NODE_TYPES = frozenset({
    "Method", "Block", "Call", "ControlStructure", "Identifier", "Literal",
    "Local", "Return", "TypeDecl", "Type", "Member", "Unknown",
})

_BY_NODE = MappingProxyType({
    "FunctionDef": "Method", "AsyncFunctionDef": "Method", "Lambda": "Method",
    "Module": "Block", "Interactive": "Block", "Expression": "Block",
    "Call": "Call",
    "If": "ControlStructure", "While": "ControlStructure", "For": "ControlStructure",
    "AsyncFor": "ControlStructure", "With": "ControlStructure", "AsyncWith": "ControlStructure",
    "Try": "ControlStructure", "TryStar": "ControlStructure", "Match": "ControlStructure",
    "Break": "ControlStructure", "Continue": "ControlStructure",
    "Name": "Identifier",
    "Constant": "Literal", "JoinedStr": "Literal", "FormattedValue": "Literal",
    "Return": "Return", "Yield": "Return", "YieldFrom": "Return", "Await": "Return",
    "ClassDef": "TypeDecl", "AnnAssign": "Member",
    "Assign": "Call", "AugAssign": "Call", "BinOp": "Call", "BoolOp": "Call",
    "UnaryOp": "Call", "Compare": "Call", "Attribute": "Call", "Subscript": "Call",
})

_OPERATORS = MappingProxyType({
    "Assign": "<operator>.assignment", "AnnAssign": "<operator>.assignment",
    "AugAssign": "<operator>.assignmentPlus",
    "Add": "<operator>.addition", "Sub": "<operator>.subtraction",
    "Mult": "<operator>.multiplication", "Div": "<operator>.division",
    "Mod": "<operator>.modulo", "Pow": "<operator>.exponentiation",
    "Eq": "<operator>.equals", "NotEq": "<operator>.notEquals",
    "Lt": "<operator>.lessThan", "LtE": "<operator>.lessEqualsThan",
    "Gt": "<operator>.greaterThan", "GtE": "<operator>.greaterEqualsThan",
    "And": "<operator>.logicalAnd", "Or": "<operator>.logicalOr",
    "Not": "<operator>.logicalNot",
    "Attribute": "<operator>.fieldAccess", "Subscript": "<operator>.indexAccess",
})


def node_type_for(ast_node_name: str) -> str:
    """Return the neutral node type for a Python AST node type name."""
    return _BY_NODE.get(ast_node_name, "Unknown")


def operator_name_for(ast_node_name: str) -> str | None:
    """Return the reserved call name for an operator node, or None."""
    return _OPERATORS.get(ast_node_name)


# Statement lists whose order is semantic, so M5 materializes an index on them.
ORDERED_FIELDS = ("body", "orelse", "finalbody")

_WRAPPERS = frozenset({"Expr", "arguments", "alias"})

TRANSPARENT = MappingProxyType({
    # ast elides nothing structural, so it round-trips. See the profile note.
    "ast": frozenset(),
    "workflow": _WRAPPERS,
    "provenance": _WRAPPERS,
    "signature": _WRAPPERS,
})

# keyword is never transparent: folding preserves the argument name.
FOLDS_KEYWORDS = MappingProxyType({
    "ast": False, "workflow": True, "provenance": True, "signature": True,
})

_EXPRESSIONS = frozenset({
    "BinOp", "BoolOp", "UnaryOp", "Compare",
    "ListComp", "DictComp", "SetComp", "GeneratorExp",
})

OPAQUE = MappingProxyType({
    "ast": frozenset(),
    "workflow": _EXPRESSIONS,
    "provenance": _EXPRESSIONS,
    "signature": _EXPRESSIONS,
})

PROFILES = tuple(TRANSPARENT)

# Ambient vocabulary: shared by every workflow, so it distinguishes nothing.
# Deliberately small. Grow it from evidence on the real corpus file, not from
# Graphify's lists, which encode what a repository is about.
AMBIENT_CALLEES = frozenset({
    "print", "len", "range", "enumerate", "zip", "isinstance", "getattr",
    "str", "int", "float", "bool", "list", "dict", "set", "tuple",
})

AMBIENT_ANNOTATIONS = frozenset({
    "Optional", "Union", "List", "Dict", "Any", "Sequence", "Iterable",
    "str", "int", "float", "bool", "bytes", "None",
})

Task 2: Keep the vocabulary closed, neutral, and the profiles distinct¶

  • [ ] Step 1: Write the tests
import pytest

from awl.vocab import (
    FOLDS_KEYWORDS, NODE_TYPES, OPAQUE, PROFILES, TRANSPARENT,
    node_type_for, operator_name_for,
)


def test_the_vocabulary_is_closed():
    assert len(NODE_TYPES) == 12


def test_control_flow_uses_one_type_with_a_discriminator():
    for name in ("If", "While", "For", "Try", "Match", "Break"):
        assert node_type_for(name) == "ControlStructure"


def test_no_vocabulary_name_is_python_specific():
    assert not (NODE_TYPES & {"AugAssign", "Expr", "arguments", "keyword", "Constant", "Name"})


def test_operators_are_calls_with_reserved_names():
    assert node_type_for("BinOp") == "Call"
    assert operator_name_for("Add") == "<operator>.addition"
    assert operator_name_for("AugAssign") == "<operator>.assignmentPlus"
    assert operator_name_for("Call") is None


def test_the_ast_profile_elides_nothing_structural():
    """Guards the regression that turned named arguments into positional ones."""
    assert TRANSPARENT["ast"] == frozenset()
    assert OPAQUE["ast"] == frozenset()
    assert FOLDS_KEYWORDS["ast"] is False


def test_keyword_is_never_transparent():
    """Folding preserves the argument name; transparency destroyed it."""
    for profile in PROFILES:
        assert "keyword" not in TRANSPARENT[profile]


@pytest.mark.parametrize("profile", ["workflow", "provenance", "signature"])
def test_reduced_profiles_fold_keywords(profile):
    assert FOLDS_KEYWORDS[profile] is True

TYPESCRIPT_EQUIVALENTS = [
    ("function_declaration", "Method"),
    ("statement_block", "Block"),
    ("while_statement", "ControlStructure"),
    ("call_expression", "Call"),
    ("new_expression", "Call"),

@pytest.mark.parametrize("ts_node,expected", TYPESCRIPT_EQUIVALENTS)
def test_the_vocabulary_has_a_home_for_typescript(ts_node, expected):
    """A second frontend must need a new mapping, not new node types.

    `call_expression` and `new_expression` are distinct in that grammar and
    the same thing semantically, which is the discriminator design earning
    its keep.
    """
    assert expected in NODE_TYPES

Acceptance¶

  • [ ] Every ast node type resolves to a member of NODE_TYPES, with Unknown as an explicit, tested fallback.
  • [ ] The vocabulary contains no Python-specific name and has exactly 12 members.
  • [ ] TRANSPARENT["ast"] and OPAQUE["ast"] are empty, and ast does not fold keywords.
  • [ ] keyword is transparent in no profile.
  • [ ] Ambient-noise lists exist here, not in a walker.
  • [ ] tests/test_vocab.py imports only awl.vocab.

Known limits¶

  • The operator table is not exhaustive over 13 binary and 10 comparison operators. operator_name_for returning None is the signal to extend it, which keeps vocabulary decisions out of the walker.
  • Local and Type have no direct ast node and are assigned by position, so M5 sets them; the table alone cannot.
  • provenance and signature currently share workflow's sets. Their distinguishing behaviour (typed boundaries only, declarations only) is not expressible as a node-type set and needs a predicate M5 supplies. Until then those two profiles are aliases, and M5's test asserts only signature <= workflow.
