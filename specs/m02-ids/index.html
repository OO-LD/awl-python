M2 awl.ids implementation plan¶

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: One place that mints identities, so every producer in the system agrees on what a given code entity is called.

Architecture: Pure functions over a declarative configuration. Identity minting is data (a path-pattern to namespace map, Kythe's vnames.json pattern), not code. Identity for an OO-LD class follows a declared precedence that mirrors get_cls_iri(), so AWL-LD and oold cannot disagree.

Tech Stack: Python stdlib only.

Contract¶
Consumes identity parts, and the type declarations M3 extracts
Produces Identity (identity.schema.json)
Depends on awl.contracts only

Why this is one module and not a helper¶

From graphify/ids.py, whose docstring states the failure directly:

Three independent producers must agree on node IDs or the graph splits a single entity into disconnected ghost nodes.

AWL-LD has the same three producers: the AST walk (M3), the collapse (M6) and the RDF projection (M8). It is worse here than in Graphify, because these identifiers are global IRIs rather than graph-local ids: a collision is a wrong assertion about the world, not a merged node in one tool's database.

Identity precedence for a class¶

Verified against the OO-LD spec, spec/sections/07-schema-instances.md.

  1. x-oold-instance-rdf-type on the schema. A list, because it co-types: it lists every rdf:type an instance asserts at once. Under allOf the nearest declaration is authoritative and replaces a base class's value rather than appending (rule OOLD-INS-559f).
  2. The inline type field default, e.g. "ex:Person" or ["Diameter"]. If both are present the inline value MUST be consistent with the schema declaration (rule OOLD-INS-4b5c).
  3. The import path, when no IRI is declared at all.

Identity is the typed instantiation, not the function¶

The refinement that makes opaque callees tractable. scipy.stats.linregress is generic linear regression; attaching (LinearStrain, Stress) -> ModulusOfElasticity to that identifier asserts it for every use of linregress on earth. The semantics belong to the typed instantiation:

scipy.stats.linregress                        no semantics, ever
scipy.stats.linregress(LinearStrain, Stress)  -> ModulusOfElasticity

This is what SCIP's method-disambiguator and Kythe's opaque signature field exist for. With OO-LD types on the arguments the instantiation is derivable statically at every call site, so a model is needed once to propose the mapping and dispatch afterwards is deterministic.

Retroactive minting. Kythe's entry store is append-only facts keyed by VName, so any analyzer may add facts later and they join everywhere the symbol was referenced. Mint the identifier for an opaque callee now; attach semantics whenever they become known; every prior reference gains meaning without reprocessing. That property is the reason identity must be stable and global before anything else is built.

Versioning¶

Decided: OO-LD classes may carry a version, from x-oold-version or a versioned $id. Other assets usually do not. Record a distribution version where package metadata is inspectable; leave the slot empty otherwise rather than guessing. Environment pinning (a Dockerfile or devcontainer) cannot be derived from Python source and is therefore not part of extraction; if a repository has one, a human or an agent assigns it on top of the extracted graph as a separate layer. The contract leaves room for that but this module does not populate it.

Non-goals¶

  • Not resolution. Deciding which identity a local name refers to is M4.
  • Not extraction. Reading declarations out of source is M3.

"""The single identity-minting authority for AWL-LD.

Every producer must route through here. Two producers that mint differently
split one entity into disconnected nodes, and because these are global IRIs
the result is a wrong assertion rather than a local inconsistency.
"""

from __future__ import annotations

import re
import unicodedata
from typing import Any

__all__ = ["DEFAULT_BASE", "normalize", "mint", "mint_instantiation", "class_identity"]

DEFAULT_BASE = "https://w3id.org/awl/"

_NON_WORD = re.compile(r"[^\w.]+", re.UNICODE)


def normalize(text: str) -> str:
    """Normalize one identifier segment, preserving case.

    Guarantees, enforced by tests:

    - idempotent: ``normalize(normalize(s)) == normalize(s)``
    - case-preserving: distinct casings stay distinct identities

    **Do not casefold.** ``graphify/ids.py`` does, and copying that recipe here
    would be a correctness bug rather than a style choice. It casefolds so
    that its LLM-produced and AST-produced ids reconcile despite punctuation
    and casing drift. AWL-LD has no probabilistic producer in this path, and
    Python is case-sensitive, so casefolding *merges genuinely different
    symbols*:

    ============================  ==================  ==========
    Input pair                    Casefolded          Preserved
    ============================  ==================  ==========
    ``battery.Params`` /          both
    ``battery.params``            ``battery.params``  distinct
    ``ChargeParam`` /             both
    ``chargeParam``               ``chargeparam``     distinct
    ============================  ==================  ==========

    That is the ghost-node failure inverted: false merging instead of false
    splitting, and a merge is the harder one to notice.
    """
    current = unicodedata.normalize("NFKC", text)
    current = _NON_WORD.sub("_", current)
    return re.sub(r"_+", "_", current).strip("_")


def mint(
    *,
    scheme: str,
    module: str = "",
    symbol: str = "",
    version: str | None = None,
    disambiguator: str | None = None,
    base: str = DEFAULT_BASE,
) -> dict[str, Any]:
    """Mint an Identity.

    Returns
    -------
    dict
        Conforms to ``identity.schema.json``. Only ``iri`` should be compared
        by consumers; the other fields are provenance for humans.
    """
    # Module and symbol are separated by "/" and not ".", or a.b::C and
    # a::b.C flatten to the same string. See the collision test.
    parts = [p for p in (normalize(module), normalize(symbol)) if p]
    iri = f"{base}{scheme}/" + "/".join(parts) if parts else f"{base}{scheme}"
    if version:
        iri = f"{iri}@{version}"
    if disambiguator:
        iri = f"{iri}#{disambiguator}"
    return {
        "iri": iri,
        "scheme": scheme,
        "module": module,
        "symbol": symbol,
        "version": version,
        "disambiguator": disambiguator,
        "aliasOf": None,
        "aliasRoot": None,
    }


def mint_instantiation(callee: dict[str, Any], arg_types: list[str]) -> dict[str, Any]:
    """Mint the identity of a *typed instantiation* of a generic callee.

    A bare function name carries no semantics; the instantiation may. See the
    linregress example in the module spec.
    """
    disambiguator = "(" + ",".join(normalize(t) for t in arg_types) + ")"
    return mint(
        scheme=callee["scheme"],
        module=callee.get("module", ""),
        symbol=callee.get("symbol", ""),
        version=callee.get("version"),
        disambiguator=disambiguator,
    )


def class_identity(
    *,
    scheme: str,
    module: str,
    symbol: str,
    instance_rdf_types: list[str] | None = None,
    type_field_default: list[str] | str | None = None,
    version: str | None = None,
) -> dict[str, Any]:
    """Mint a class identity, following the OO-LD precedence.

    x-oold-instance-rdf-type wins, then the inline type field default, then
    the import path. Mirrors get_cls_iri() so AWL-LD and oold cannot disagree.
    """
    declared = instance_rdf_types or []
    if not declared and type_field_default:
        declared = (
            [type_field_default] if isinstance(type_field_default, str) else list(type_field_default)
        )
    identity = mint(scheme=scheme, module=module, symbol=symbol, version=version)
    # The minted IRI stays authoritative and resolvable. A declared type is
    # usually a CURIE ("ex:ChargeParam") against a prefix this package does
    # not control; overwriting `iri` with it produced predicates like
    # `ex:ChargeParam#target_voltage`, which rdflib accepts and which join
    # with nothing. Declared types are carried alongside, not instead.
    identity["declaredTypes"] = declared
    return identity

Task 2: Property tests on normalisation¶

Two collision classes, both found by testing rather than by review. Neither is hypothetical.

  • [ ] Step 1: Write the tests
import pytest

from awl.ids import mint, normalize

SAMPLES = ["ChargeParam", "charge_param", "Ärger", "İslemYap", "a..b", "  x  ", "Straße"]


@pytest.mark.parametrize("text", SAMPLES)
def test_normalize_is_idempotent(text):
    assert normalize(normalize(text)) == normalize(text)


@pytest.mark.parametrize(
    "left,right",
    [("battery.Params", "battery.params"), ("ChargeParam", "chargeParam")],
)
def test_case_is_significant(left, right):
    """Python is case-sensitive, so these name different things.

    Casefolding, as graphify/ids.py does, merges them. That is a false merge,
    which is harder to notice than a false split because the graph simply
    contains one node where it should contain two.
    """
    assert normalize(left) != normalize(right)


def test_module_and_symbol_boundaries_survive():
    """a.b::C and a::b.C are different entities and must mint differently.

    Joining with "." loses the boundary and both flatten to a.b.C.
    """
    assert (
        mint(scheme="py", module="a.b", symbol="C")["iri"]
        != mint(scheme="py", module="a", symbol="b.C")["iri"]
    )

Task 3: OO-LD precedence and typed instantiation¶

  • [ ] Step 1: Write the tests
from awl.ids import class_identity, mint, mint_instantiation


def test_the_minted_iri_is_always_resolvable():
    """A declared type never replaces the minted IRI.

    Declared types are usually CURIEs against a prefix this package does not
    control. Using one as the identity produced `ex:ChargeParam#target_voltage`
    predicates, which validate and join with nothing.
    """
    identity = class_identity(
        scheme="py", module="battery.params", symbol="ChargeParam",
        instance_rdf_types=["ex:ChargeParam"],
    )
    assert identity["iri"].startswith("https://w3id.org/awl/")
    assert identity["iri"].endswith("battery.params/ChargeParam")


def test_declared_types_are_carried_in_precedence_order():
    """x-oold-instance-rdf-type co-types, so every declared IRI is kept."""
    identity = class_identity(
        scheme="py", module="battery.params", symbol="ChargeParam",
        instance_rdf_types=["ex:ChargeParam", "qudt:QuantityValue"],
        type_field_default=["ex:Ignored"],
    )
    assert identity["declaredTypes"] == ["ex:ChargeParam", "qudt:QuantityValue"]


def test_the_type_field_default_is_used_when_no_schema_declaration():
    identity = class_identity(
        scheme="py", module="battery.params", symbol="ChargeParam",
        type_field_default="ex:ChargeParam",
    )
    assert identity["declaredTypes"] == ["ex:ChargeParam"]


def test_an_undeclared_class_has_no_declared_types():
    identity = class_identity(scheme="py", module="battery.params", symbol="ChargeParam")
    assert identity["iri"].endswith("battery.params/ChargeParam")
    assert identity["declaredTypes"] == []


def test_a_generic_callee_and_its_instantiation_differ():
    """The whole point: linregress carries no semantics, the instantiation may."""
    generic = mint(scheme="py", module="scipy.stats", symbol="linregress")
    typed = mint_instantiation(generic, ["LinearStrain", "Stress"])
    assert typed["iri"] != generic["iri"]
    assert typed["iri"].startswith(generic["iri"])


def test_identity_validates_against_the_contract():
    from awl import contracts

    contracts.validate(mint(scheme="py", module="a", symbol="B"), "identity")

Acceptance¶

  • [ ] normalize is idempotent and caseless-stable across the sample set.
  • [ ] Distinct module/symbol splits do not collide.
  • [ ] x-oold-instance-rdf-type beats the type field default beats the import path.
  • [ ] Co-typing survives: declaredTypes keeps every declared IRI, not just the first.
  • [ ] A generic callee and a typed instantiation get different IRIs.
  • [ ] Output validates against identity.schema.json.
  • [ ] tests/test_ids.py imports only awl.ids and awl.contracts.

Known limits¶

  • The path-pattern configuration (Kythe's vnames.json equivalent) is not implemented here; base is a single default. Add it when a second corpus needs a different namespace, not before.
  • aliasOf and aliasRoot are minted empty. Populating them is M4's job, because it requires resolution.
