M4 awl.resolve implementation plan¶

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

Goal: Decide what each local name at each call site actually refers to, and record how confident that decision is.

Architecture: A pure function from SymbolFacts to ResolvedNames. Every binding carries EXTRACTED, INFERRED or AMBIGUOUS. Nothing is guessed silently.

Tech Stack: Python stdlib. Possibly Scalpel's FQN Inferrer or PyCG; decided during implementation, since the contract does not depend on it.

Contract¶
Consumes SymbolFacts from M3
Produces ResolvedNames
Depends on awl.contracts, awl.ids

Confidence is part of the data model, not metadata¶

Tier Means Example
EXTRACTED Literally in the source from battery.device import charge, then charge(...)
INFERRED A reasonable deduction resolved through a re-export chain
AMBIGUOUS Uncertain, flagged reached via import *, or a name with two candidate definitions

This becomes load-bearing once meaning can be retrofitted by a model: declared and inferred semantics must never be indistinguishable. A pipeline that cannot mark its own output is worse than no pipeline. In RDF this is expressed with named graphs, which is M8's problem; here it is a field.

Known failure modes¶

Mode Handling
Aliases (import numpy as np) Local, resolvable from the import table. EXTRACTED
Re-exports (from .impl import Thing, then pkg.Thing) Emit both the alias hop and the root, per Kythe's aliases/aliases/root. INFERRED
Overloads (typing.overload, functools.singledispatch) Needs SCIP's method-disambiguator. Until then, AMBIGUOUS
Star imports Nothing in the survey handles these soundly. Resolve to AMBIGUOUS and let the domain schema forbid import *
Not in the scanned set AMBIGUOUS, never a fabricated identity

Do not write a general resolver¶

Stack graphs is the state of the art for incremental cross-file name resolution, and it is archived (last pushed 2025-09-09). AWL-LD's problem is far smaller: resolve call targets within one document plus its declared imports. Evaluate Scalpel's FQN Inferrer (last pushed 2024-03-28) and PyCG before writing anything; vendor if the maintenance risk is acceptable.

Decided during implementation: a minimal resolver, no vendoring. The judgement is a lookup in an import table plus an optional hop through another module's exports, which is under a hundred lines. Both candidates carry a whole call-graph model this contract does not consume, and both would have to be kept working against new Python syntax for the sake of the part that is already written. The decision is cheap to revisit precisely because the contract does not mention either of them.

Correction: re-export resolution needs a second module's facts¶

The task 3 sketch put the intermediate module's imports and the origin module's exports in one SymbolFacts document. No such document exists: extraction is per file, so those two facts come from two files. Written that way the test would have passed while encoding a model that cannot occur.

resolve(facts, *, index=None) takes an optional mapping of module path to that module's SymbolFacts. Without it resolution is per file and a re-export is simply EXTRACTED against the module named at the import site, which is what the source literally says. With it, a name whose intermediate module re-exports it is followed one hop and downgraded to INFERRED.

This also requires extraction to record, for a module-level import, that the name became importable from this module and where it came from. from .impl import Thing at module level genuinely makes Thing importable from here; that is an observation, not an inference.

Non-goals¶

  • Not extraction. Reading facts is M3.
  • Not minting. Building the IRI is M2.
  • Not cross-repository indexing.

"""Inference: bind names to identities, and say how sure we are."""

from __future__ import annotations

from typing import Any

from awl.ids import mint

__all__ = ["resolve"]


def resolve(facts: dict[str, Any], *, scheme: str = "py") -> dict[str, Any]:
    """Bind each use to an identity with a confidence tier.

    Parameters
    ----------
    facts : dict
        A ``SymbolFacts`` document from M3.
    scheme : str
        Language dimension passed through to minting.

    Returns
    -------
    dict
        Conforms to ``resolved-names.schema.json``.
    """
    by_name = {i["localName"]: i for i in facts.get("imports", [])}
    star = any(i["importedName"] == "*" for i in facts.get("imports", []))

    bindings = []
    for use in facts.get("uses", []):
        name = use["localName"]
        imported = by_name.get(name)
        if imported is not None:
            identity = mint(scheme=scheme, module=imported["fromModule"], symbol=imported["importedName"])
            confidence = "EXTRACTED"
        elif star:
            identity, confidence = None, "AMBIGUOUS"
        else:
            identity, confidence = None, "AMBIGUOUS"
        binding = {"localName": name, "span": use["span"], "confidence": confidence}
        if identity is not None:
            binding["identity"] = identity
        bindings.append(binding)
    return {"file": facts["file"], "bindings": bindings}

Task 2: Refuse to guess¶

The most important behaviour in the module, so it is tested hardest.

  • [ ] Step 1: Write the tests
import copy


def test_a_star_import_never_produces_an_identity():
    """No surveyed system resolves these soundly. Fabricating one would be worse
    than admitting ignorance, because a wrong identity merges two entities.
    """
    facts = copy.deepcopy(FACTS)
    facts["imports"] = [{"localName": "*", "importedName": "*", "fromModule": "battery.device", "isAlias": False}]
    binding = resolve(facts)["bindings"][0]
    assert binding["confidence"] == "AMBIGUOUS"
    assert "identity" not in binding


def test_an_unknown_name_is_ambiguous_not_invented():
    facts = copy.deepcopy(FACTS)
    facts["imports"] = []
    binding = resolve(facts)["bindings"][0]
    assert binding["confidence"] == "AMBIGUOUS"
    assert "identity" not in binding


def test_output_matches_the_contract():
    from awl import contracts

    contracts.validate(resolve(FACTS), "resolved-names")

Task 3: Re-exports keep both hops¶

  • [ ] Step 1: Write the test
def test_a_re_export_records_both_the_hop_and_the_root():
    """Kythe emits aliases and aliases/root so a query picks its indirection.

    Without both, `pkg.Thing` and `pkg.impl.Thing` become two nodes for one
    entity, which is the likeliest duplicate source in Python.
    """
    facts = copy.deepcopy(FACTS)
    facts["imports"] = [
        {"localName": "Thing", "importedName": "Thing", "fromModule": "pkg", "isAlias": False}
    ]
    facts["exports"] = [{"exportedName": "Thing", "fromModule": "pkg.impl"}]
    facts["uses"] = [{"localName": "Thing", "span": FACTS["uses"][0]["span"]}]

    binding = resolve(facts)["bindings"][0]
    assert binding["confidence"] == "INFERRED", "following a re-export is a deduction"
    assert binding["identity"]["aliasOf"] == "pkg"
    assert binding["identity"]["aliasRoot"].endswith("pkg.impl/Thing")

def test_an_aliased_import_resolves_to_the_original_name():
    """`import numpy as np` is ubiquitous, including in the real corpus file."""
    facts = copy.deepcopy(FACTS)
    facts["imports"] = [
        {"localName": "np", "importedName": "numpy", "fromModule": "", "isAlias": True}
    ]
    facts["uses"] = [{"localName": "np", "span": FACTS["uses"][0]["span"]}]

    binding = resolve(facts)["bindings"][0]
    assert binding["confidence"] == "EXTRACTED", "an alias is local and unambiguous"
    assert binding["identity"]["iri"].endswith("numpy")
    assert binding["identity"]["aliasOf"] == "np", "the hop as written is kept"


def test_an_overloaded_callee_is_ambiguous_until_disambiguated():
    """functools.singledispatch and typing.overload give one name several
    definitions. A bare FQN cannot name them apart, so picking the first
    would be a fabricated identity.
    """
    facts = copy.deepcopy(FACTS)
    facts["declarations"] = [
        {"name": "handle", "kind": "function", "decorators": ["singledispatch"]},
        {"name": "handle", "kind": "function", "decorators": ["handle.register"]},
    ]
    facts["imports"] = []
    facts["uses"] = [{"localName": "handle", "span": FACTS["uses"][0]["span"]}]

    binding = resolve(facts)["bindings"][0]
    assert binding["confidence"] == "AMBIGUOUS"
    assert "identity" not in binding

Acceptance¶

  • [ ] A direct import resolves EXTRACTED.
  • [ ] A re-export resolves INFERRED and carries both aliasOf and aliasRoot.
  • [ ] A star import and an unknown name resolve AMBIGUOUS with no identity field.
  • [ ] Output validates against resolved-names.schema.json.
  • [ ] tests/test_resolve.py imports only awl.resolve, awl.ids and awl.contracts.

Known limits¶

  • Overloads are AMBIGUOUS until a disambiguator scheme lands. Do not silently pick the first definition.
  • Conditional and function-local imports are not handled; they are AMBIGUOUS.
  • Resolution is per-file. A cross-repository index is explicitly out of scope.
